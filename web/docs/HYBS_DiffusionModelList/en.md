# Diffusion Model List

Creates a LIST of selected UNet / diffusion model filenames from `models/unet`.

Start with one selector. Selecting a model adds the next selector. `count` includes only actual model selections. Use `model names` as labels for ComfyLab XY Plot when needed.

## Outputs

- **model names**: Selected filenames in visible-row order.
- **count**: Number of selected models.
