# Resolution Selector

`config/resolution_combos.json` から解像度を選び、`width` と `height` を出力します。設定ファイルがない場合は内蔵の既定値を使用します。

## 設定

`config/resolution_combos.json.example` を `config/resolution_combos.json` にコピーして編集します。文字列は表示専用の見出し、正の整数ペアは選択可能な解像度です。見出しはグレー表示になり、従来の描画方式とNodes2.0のどちらでもマウス・キーボード操作で選択できません。

```json
[
  "1024 x 1024 相当",
  [896, 1152],
  [1152, 896],
  [1024, 1024],
  "1280 x 1280 相当",
  [1120, 1440],
  [1440, 1120],
  [1280, 1280]
]
```

最低1つの解像度ペアが必要です。従来の数値ペアのみのファイルも使用できます。サンプルには1024・1280・1536・1792・2048相当の5区分を収録しています。このノードの候補を更新するには、設定変更後にComfyUIを再起動し、ブラウザを再読み込みしてください。

## 入出力

- **resolution**: 選択した `<width>x<height>` 形式の値。見出しは値として保存されません。
- **width**、**height**: 選択した整数の幅と高さ。

既存ワークフローの入力名と保存形式は維持します。見出しの「相当」は設定したラベルであり、自動計算による分類ではありません。
