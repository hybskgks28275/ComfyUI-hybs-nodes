# Load LoRA Stack

LoRAをフォルダツリーから選び、MODELとTE（CLIP）の両方、または片方に適用します。
カテゴリ: `HYBS/LoRA`。ノードID: `HYBS_LoadLoRAStack`。

各行のMODELとTE / CLIPの強度は横並びです。行の`ON / OFF`トグルで、LoRA名・強度・行を残したまま適用を切り替えられます。OFFの行はファイルを読み込まず、適用済みトークンにも含めません。ON / OFF状態も保存・復元されます。以前のワークフローでは各行がONとして読み込まれます。

- `model`、`clip`の片方または両方を接続します。どちらも任意入力です。未接続側の出力は`None`です。
- LoRAボタンを押すとフォルダツリーを開きます。フォルダを展開して選択するか、フォルダ名・ファイル名で検索できます。検索結果も階層を維持します。同名ファイルが別フォルダにあっても、相対パスで区別します。
- 初期値の`NONE`ではLoRAを適用せず、接続した入力をそのまま返します。ファイルの指定やenableトグルの操作は不要です。
- MODELとTE / CLIPの強度は個別に-20〜20で指定できます。±を押すと0.01ずつ変更し、350ms以上長押しすると連続で増減します。ボタンを離す、ポインター操作をキャンセルする、ウィンドウがフォーカスを失うと停止します。数値の直接入力も可能です。
- `applied lora`は適用済みの`<lora:名前:MODEL強度:CLIP強度>`を空白区切りで返します。未使用時は空文字です。未接続側の強度は0として扱い、両側の実効強度が0の行はファイルを読み込みません。
- `Add LoRA`で行を増やし、各行の`Remove`で削除できます。各行でLoRAとMODEL／TE強度を個別に指定し、上から順に適用します。同じLoRAの重複指定も可能です。0行まで削除すると未適用で通過します。行数・選択・強度は保存・復元され、従来の1行版ワークフローも読み込めます。既存の`Load LoRA`も引き続き利用できます。

導入後はComfyUIを再起動し、ブラウザを再読み込みしてください。選択した相対パスと強度はワークフローに保存されます。専用UIは通常の入力値に反映され、APIからも指定できます。
